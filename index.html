Tools & Technologies Used in Modern DevOps

🐳 Docker

Containerization platform used to package applications and dependencies into portable containers.

☸️ Kubernetes

Container orchestration platform that automates deployment, scaling, and management of containers.

🏗️ Terraform

Infrastructure as Code tool used to provision and manage cloud resources.

⚙️ Jenkins

Popular CI/CD tool used to automate software build, test, and deployment pipelines.

☁️ AWS

Cloud platform offering services like EC2, S3, EKS, RDS, Lambda, and more.

📊 Prometheus & Grafana

Monitoring and observability stack used for metrics collection and visualization.

🔒 DevSecOps

Integrates security practices into the DevOps lifecycle for secure software delivery.

🔄 CI/CD Pipeline

Automates code integration, testing, and deployment to accelerate software releases.
